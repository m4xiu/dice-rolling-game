# 🎲 Dice Rolling Game in Python

A simple and fun command-line Dice Rolling Game built using Python. Roll the dice as many times as you want and get a random number between 1 and 6, just like a real dice!

## 🚀 Features

- Random dice rolls between 1 and 6
- User-friendly command-line interface
- Play multiple rounds
- Beginner-friendly Python project
- Uses Python's built-in `random` module

## 🛠️ Technologies Used

- Python 3
- Random Module
